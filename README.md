# Andrey Fitness App

Модульное web-приложение для сопровождения клиентов по питанию, тренировкам и прогрессу.

## Что уже заложено

- роли `trainer` / `client`;
- модульное подключение услуг для каждого клиента;
- тренировки, питание, прогресс, чек-ины, напоминания;
- библиотека упражнений, группы мышц и группы замен;
- шаблоны программ тренировок и питания;
- индивидуальные настройки клиента поверх шаблона;
- обязательные и необязательные поля;
- клиент может скрывать только разрешённые необязательные показатели;
- Telegram/email/web-push контур уведомлений;
- Supabase Auth + PostgreSQL + Row Level Security;
- адаптивный интерфейс для телефона;
- безопасный preview-режим.

## Локальный запуск на Windows

1. В GitHub Desktop нажать **Pull origin**.
2. Открыть папку репозитория.
3. Один раз запустить `setup.bat`.
4. Затем запускать `start.bat`.

Приложение откроется на:

`http://localhost:5173`

## Технологии

- React
- TypeScript
- Vite
- Supabase
- React Router
- Lucide icons

Для надёжной публикации в подпапке обычного FTP-хостинга используется `HashRouter` и относительная сборка Vite.

## Supabase

Frontend использует только **publishable key**. Это публичный браузерный ключ; реальные права определяются политиками RLS в PostgreSQL.

Никогда не добавлять во frontend:

- `service_role`;
- secret key;
- пароль базы;
- Telegram bot token.

### Главный принцип

Интерфейс собирается из модулей, назначенных конкретному клиенту.

Например:

- только тренировки;
- только питание;
- тренировки + питание;
- питание + прогресс;
- полный набор.

Разделы, которых нет в сопровождении, клиент вообще не видит.
